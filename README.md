# My Husband's Daily Adventures

A humorous website that playfully tracks and displays various habits and behaviors of a workaholic husband. Built with HTML, CSS, and JavaScript.

## Features

- Work time tracker
- Phone addiction level indicator
- Bathroom time counter
- Anger level meter
- Interactive mood selector
- Random fun facts popup
- Responsive design

## Setup

1. Clone the repository
2. Open `index.html` in your browser
   
   OR
   
   Run a local server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
